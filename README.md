# Raj Gold

Marketing site for Raj Gold Company, a gold bar dealer — built to give the business a real online presence with live contact/enquiry channels instead of relying on walk-ins alone.

**Live:** https://rajgold.vercel.app

## What it does

- **Landing page** with hero, trust/credibility section, testimonials, and FAQ built as animated sections (Framer Motion + GSAP).
- **Contact form** using `react-hook-form` + `zod` for client-side validation before submission.
- Click-to-call and direct enquiry paths for visitors coming from mobile.

## Tech stack

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS v4
- Framer Motion + GSAP for animation
- react-hook-form + zod for form handling/validation

## Running it locally

```bash
git clone https://github.com/DeepakJaggupalli/rajgold.git
cd rajgold
npm install
npm run dev
```

Open `http://localhost:3000`.
